This Week in AI

OpenAI Ships Three Realtime Voice Models — and the Pricing Rewrites What's Possible for AV

OpenAI released three new audio-class models to the Realtime API on May 11. None of them are a flagship LLM release. All three change what's economically viable inside an AV workflow.

GPT-Realtime-2 — the voice-agent model. GPT-5-class reasoning, 128K token context window, parallel tool calling, and a unified audio + text interface. Pricing per million tokens:

  • Text: $4.00 input / $24.00 output / $0.40 cached input
  • Audio: $32.00 input / $64.00 output / $0.40 cached input
  • Image: $5.00 input / $0.50 cached input

GPT-Realtime-Translate — streaming speech-to-speech translation across 70+ input languages into 13 output languages, priced by audio duration rather than by token: $0.034 per minute ($0.00057/second), or roughly $2.04 per hour.

GPT-Realtime-Whisper — streaming low-latency speech-to-text transcription, also priced by duration: $0.017 per minute ($0.00028/second), or roughly $1.02 per hour.

Why the pricing matters more than the models do. AV teams have been doing transcription, translation, and voice work with AI for years now. The block has never been capability — Whisper has been good enough for most cases since 2023, and translation systems have shipped with comparable quality intermittently since 2024. The block has been the unit economics. Real-time transcription at $1/hour, real-time translation at $2/hour, and a voice agent that can call tools mid-conversation at audio-token rates that come to roughly $1–$2 per minute of intensive use — that combination means a producer can leave transcription running over an eight-hour shoot day for $8, can dub a 25-minute scratch track to twelve languages for less than a dollar per language, and can prototype an on-set translator app for an international shoot for the price of two takeaway lunches per day.

For AV teams, the immediate use cases are obvious — captioning, dubbing rough cuts for international clients, on-set translation for foreign-language interviews, voice notes that auto-summarize and route to the right slack channel. The less-obvious use case is the voice agent as a workflow surface: an editor can talk to an agent that has tool access to Premiere, Frame.io, and the project's metadata, in actual conversation, with sub-2-second response latency. The voice-agent prototype that's been six months from shippable is now an afternoon of API integration.

Three SDKs (Python, Node, mobile) shipped alongside the model release. GPT-Realtime-2 supports parallel tool calls (the agent can fire multiple MCP calls in a single response), and the context window comfortably holds an entire post-production session.

The Compute Capacity Wars: Anthropic Locks Down 220K GPUs via SpaceX, Doubles Claude Code Limits

Anthropic announced an exclusive compute deal with SpaceX on May 6 that flipped a meaningful capacity switch for anyone whose workflow runs through Claude. The deal is interesting on two levels: the concrete user impact landed the same day the announcement did, and the structural framing is the first major model provider taking position in what's increasingly looking like a physical-infrastructure scramble.

The deal: Anthropic gets exclusive use of all compute output from SpaceX's Colossus 1 data center in Memphis — over 300 megawatts of new capacity, more than 220,000 NVIDIA GPUs (H100, H200, and GB200 accelerators), all coming online within one month. SpaceX continues to own and operate the facility. Anthropic separately expressed interest in partnering with SpaceX to develop "multiple gigawatts of orbital AI compute capacity" — still exploratory, no timeline, but on the record.

The same-day impact for Claude users, effective May 6:

  • Claude Code five-hour rate limits doubled for Pro, Max, Team, and seat-based Enterprise plans
  • Peak-hours throttling removed for Pro and Max accounts (no more degraded responses during US business hours)
  • Claude Opus API rate limits substantially raised for managed and direct API customers

A separate announcement on May 11 made Claude Platform on AWS generally available: AWS customers can now access the full platform (Managed Agents, code execution, skills, web search, Files API) with native AWS authentication, billing, and IAM. The two announcements stack — Anthropic now has both meaningfully more direct compute and a distribution channel through every existing AWS enterprise account.

Why this matters for AV. The first-order story is that anyone who uses Claude Code for production work, Claude Opus for research drafting, or Claude as the backend behind a custom agent now has a real-world capacity bump and one less peak-hour-throttling problem to plan around. The second-order story is harder to ignore: model providers are increasingly betting on physical infrastructure deals (Anthropic ↔ SpaceX, OpenAI ↔ Stargate, Google's own TPU vertical integration) rather than commodity cloud GPU rentals. The capacity question is becoming a structural fact about who can serve sustained inference at scale — and for AV teams whose workflows depend on a particular model being responsive on a deadline, the provider-to-power-grid line is now a relevant lens.

Cannes Pulse: An Open-License AI Disclosure Standard, and Soderbergh's First AI-Assisted Documentary

Two threads from Cannes 2026 deserve flagging together, because they're answering the same question — how does AI sit inside a mainstream production — from opposite ends of the stack.

Human Provenance in Film launched May 13 at the Marché du Film. The Mise En Scène Company released the standard as a free, open-license disclosure framework any producer, distributor, or platform can adopt. Three designations:

  • No AI Used — no generative AI in the production pipeline at all
  • Assistive AI — AI used for non-creative tasks (transcription, captioning, color correction assist, metadata, search)
  • Generative AI — generative AI used in creative output (image, audio, video, performance)

The framework is the first industry-led, voluntary disclosure standard to ship with a license that lets any platform adopt it without negotiation. It's an attempt to settle the "what counts as AI?" debate by separating the kind of AI use from the fact of AI use. The expectation in the room at Cannes is that some streamer or distributor will require disclosure to this standard within 18 months — possibly within the next negotiating cycle.

Steven Soderbergh premiered "John Lennon: The Last Interview" at the festival with approximately 10% AI-generated footage of Lennon and Yoko Ono. Soderbergh's framing for the AI work: sequences "that couldn't have been filmed in real life." The film uses AI to fill historical gaps where source material doesn't exist, rather than to extend or replace human performances. It's the first documentary from a top-tier American director to ship with a disclosed generative-AI segment of meaningful size.

The two together are the story. Disclosure standard and marquee-director use case landing in the same week, at the same festival, two days apart. The industry that spent 2023–2025 litigating whether AI belongs in production is, at Cannes 2026, building the conventions that will govern how it does. Films at the Marché now arrive with a disclosure declaration in their press kits. The next 24 months are about how rigid those conventions become — voluntary now, contractual within two contract cycles, regulated eventually.

The Cannes signal is consistent with the Marché's broader programming this year: the AI for Talent Summit doubled in length (May 15–16), the Village Innovation expanded to a record 1,000 square-meter space, and the Innovative Dreams and Creator Economy strands both prominently featured AI-native projects.

Krea 2 Ships a Style-First Foundation Image Model

Krea released Krea 2 on May 12 — its first foundation image model built from scratch, with an explicit design bet on style transfer and aesthetic control rather than open-ended generation. The release is small in headline capability but interesting in positioning, because Krea is the first foundation-model lab to explicitly carve out a category split: generation versus direction.

What's new:

  • Style transfer system — pass in one or more reference images; the model decomposes their aesthetic features (palette, grain, depth, lighting, composition language) and reapplies them to generated outputs
  • Moodboards — multi-style mixing, where the influence of each reference can be slider-adjusted independently
  • Style-strength control — generate the same subject across a spectrum from "loose interpretation of the reference" to "near-mimicry"
  • ~15-second generation time

The benchmark context. In Contra Labs' style-fidelity testing, Krea 2 Large ranked #2 behind only GPT Image 2, scoring 0.14 points below the leader. Stable Diffusion 3.5, FLUX Pro, and Midjourney v8.1 sit further down the table for style-specific work.

For AV teams, the use case is direct: storyboarding to a director's reference deck, mood-board-driven previsualization, brand-style work where the client comes with three campaigns of existing visual language they want extended, and any workflow where the question isn't "make me something cool" but "give me this in that style." Open-ended generation models will produce a striking image; Krea 2's bet is that producing the specific image you already see in your head is the more valuable problem to solve.

The Krea team has been transparent that the model is the foundation for an expanding product surface — style-locked video extensions and a more controllable inpainting pass are both on the roadmap.

Flick Raises $6M for AI-Native Filmmaking — With an Explicit "Cinematic Control" Pitch

Flick announced a $6M seed round on May 11, led by True Ventures with participation from GV (Google Ventures), Y Combinator, Lightspeed, Formosa Capital, Pioneer Fund, Olive Tree Capital, and N1, plus angels. The company was founded by Zoey Zhang (award-winning filmmaker, multiple festival selections) and Ray Wang (founding engineer on Instagram Stories).

The positioning is the story. Flick is explicitly not building one-click-generation tooling. The pitch deck argues that the gap in AI filmmaking right now isn't quality — it's direction. Most generative video tools produce striking 8-second clips but provide little affordance for the working filmmaker's actual job: making a series of decisions about framing, pacing, performance, and continuity, and iterating on each one until the cut works. Flick is building the iteration surface — shot-by-shot directional control, performance refinement on existing generations, and a continuity layer that enforces character/lighting/wardrobe consistency across cuts.

The Filmmaker Residency is the other notable piece. Flick is funding 10+ short AI-native films by emerging filmmakers, with showcase slots at Cinequest Film Festival, MIT, and Omni AI Film Festival. The residency frames the company as a creative-community play, not just a tool — and seeds the platform with a portfolio of high-craft work shipping over the next 12 months.

For AV teams, the relevance is the positioning more than the product. Flick is the third high-profile bet in six weeks (alongside Buzzy's "Photoshop for AI video" play and amersia's Woven, below) on the thesis that the next phase of AI video is direction and editing tooling, not better base models. If the bet is right, the AV teams that move first on direction-focused workflows get a 12–18-month head start on whoever waits for the tools to mature.

amersia + Woven Launch Out of "Critterz" — The Stack That Made the Film Becomes a Product

Two weeks ago, AGC Studios boarded "Critterz" for worldwide sales at the Cannes Marché — the first $30M mainstream commercial AI-assisted animated feature. This week, Vertigo Films and Federation Studios announced amersia, a new AI entertainment company, and its first technology product: Woven.

The setup: Critterz was made with a proprietary production stack — image generation, GPT-5 for structural work, custom pipeline tooling, and human-led creative direction throughout. Vertigo and Federation co-financed and produced the film. They've now spun the underlying technology into a standalone company.

Woven's positioning: built around human-led creativity, designed to automate repetitive production tasks (asset generation passes, continuity checks, version control across iterations, technical handoffs) rather than replace artistic judgment. Director Nik Kleverov: "Woven is built around human-led creativity." The product is positioned for animation studios, but the underlying primitives map directly to live-action production work that has the same repetitive-task characteristics.

Why this is a category move, not just a product launch. The pattern over the next 12 months is going to be: marquee AI-assisted project ships → underlying tech gets spun out → spun-out product becomes the playbook for the next 4–6 projects. amersia is the first cleanly executed example of that pattern at scale. The question for AV teams is which of the major AI-assisted features in the next year (Bitcoin: Killing Satoshi, Answr, the Storyverse slate) follow the same play.

Common Threads

The Pricing of Voice Just Collapsed

A real-time speech-to-text endpoint at $1.02/hour and a real-time translation endpoint at $2.04/hour are not a technical breakthrough. They're a unit-economics breakthrough. The technical capability has been ambient for at least 18 months. What changed this week is that an AV team can leave transcription running across an entire shoot day for the cost of a coffee, and can prototype an on-set translator app at a per-day cost that's irrelevant to any production budget. When the price of a capability drops below the threshold where it has to be justified, the capability stops being an experiment and becomes the default. That transition happened to voice this week.

The conversation at Cannes is no longer "should AI be in films?" The conversation is "how do we disclose it, how do we credit it, how do we contract for it, how do we let buyers and audiences differentiate between projects that did and didn't use it?" Tip of the Week

Build Your First Reusable AI Skill This Weekend

Last week we made the case for writing a one-page personal context file — the foundation layer of the Agent OS framework. This week's tip is the natural next step: turn one recurring task you do every week into a reusable "skill."

The problem it solves. Even with a strong context file in place, every individual prompt still re-explains the task. "Summarize this call into action items, decisions made, and follow-up owners — keep it under 200 words, use bullet points, and flag anything that needs my approval." You write that sentence every Friday. You'll write it 52 times this year. A skill is the same instruction, but written once and named — so next Friday you just say "use my call-summary skill" and the AI runs the exact same playbook.

What goes in a skill. Three things, one page or less per skill:

1. When to use it — the trigger condition. "When I paste a meeting transcript and say 'summarize this,' run the call-summary skill."

2. The steps — the actual instructions. The clearer the better. "Identify decisions made and who's responsible. Identify open questions and who needs to answer them. Identify any commitments I personally made. Use bullet points. Keep under 200 words. Flag anything that needs my approval with 🚩 [Use the emoji literally — that's the visual signal you'll scan for.]"

3. The output format — the literal template. "## Decisions / ## Open Questions / ## My Commitments / ## Flagged for Review" — so the output lands looking the same every time.

The starter list. Five tasks every AV professional does weekly that should be your first five skills:

  • Call summary — meeting/client/vendor calls turned into structured action items
  • Status update draft — week-in-review format you send to your manager or stakeholders
  • Email triage — paste a thread, get a one-line summary and a draft reply
  • Shot list scaffold — script or scene description in, structured shot list out
  • Asset metadata pass — clip file or thumbnail in, suggested keywords/tags/description out

Where to drop them. Same places as last week's context file — ChatGPT Custom Instructions, a Claude Project, an AGENTS.md for agentic tools, or a markdown file you paste from. Build one skill this weekend. Build the second next weekend. By the end of a quarter you have a dozen skills running, and you've stopped re-explaining the same task forever.

This is Step 2 of the Agent OS framework. Last week was Identity + Context (who you are, what your work is). This week is Skills (what you ask AI to do, captured as reusable instruction sets). Next week we'll cover Memory — how to make the AI remember what you've already worked through together.
