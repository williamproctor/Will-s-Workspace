# Team Memory

Shared knowledge base across all agents working in this workspace. Every agent should read this file at session start and append learnings at session end (per the auto-memory-extraction rule).

## How to Use

- **Read first.** Check this file before starting work to avoid repeating past mistakes or re-discovering known patterns.
- **Append at end.** Before closing a session, add any decisions, failures, wins, or discoveries under the appropriate section.
- **Keep entries atomic.** One bullet per insight. Include the date and enough context that a future agent can act on it without asking follow-up questions.
- **Never delete entries.** Mark outdated items with `[SUPERSEDED yyyy-mm-dd]` and add the replacement entry.

## Format

```
- yyyy-mm-dd — [CATEGORY] description (context if needed)
```

Categories: `DECISION`, `FAILURE`, `WIN`, `DISCOVERY`, `PATTERN`, `WARNING`

- 2026-04-02 — [WARNING] WebM (VP9 4K) re-encoding to H.264 at CRF 18 is extremely slow and produces bloated files (~200MB for 3.5min). Use `-vf scale=1920:1080 -preset veryfast -crf 23` instead — completes in ~4 min per clip with reasonable file sizes (~37MB for 3.5min). Always check source resolution with ffprobe before choosing encode settings.
